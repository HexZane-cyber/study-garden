## 先判断自己在哪一层

| 当前能独立完成的事情 | 建议起点 |

## 分支一：数字 IC 与 EDA

建议顺序：[数字逻辑](courses/ee-digital.md) → [CMOS 数字 IC](courses/ic-digital.md) → [HDL 与数字系统实验](courses/ic-fpga.md) → [RTL 到 GDS 实践](courses/ic-eda.md)。器件基础贯穿其中；HDL 实验与 CMOS 基础也可以在掌握各自先修后并行。

| 训练阶段 | 应当能解释 | 项目产物 |
| --- | --- | --- |
| RTL 与验证 | 时钟、复位、接口时序；仿真覆盖了什么 | UART、FIFO 或 SPI 控制器之一，附 testbench 与波形 |
| CMOS 基本单元 | 负载、驱动、延迟、功耗的关系 | 一组反相器链参数扫描与比较 |
| 实现流程 | 综合、布局、时钟树和布线分别产生什么 | 工具版本、约束、日志、面积与时序报告 |

不要一开始就做复杂 CPU。一个边界条件清楚、测试充分、能说明失败原因的小模块，比无法解释的“大工程”更适合展示自己的工作。

## 分支二：模拟 IC 与器件

建议顺序：[器件](courses/ee-devices.md) → [模拟电子实验](courses/ee-analog.md) → [信号与系统](courses/ee-signals.md) → [模拟电路进阶](courses/ic-analog.md)。面向数据转换与混合信号时，再加入[数字信号处理](courses/ee-dsp.md)；高速互连或射频兴趣可补[电磁场与应用](courses/ee-em.md)。

| 训练阶段 | 应当能解释 | 项目产物 |
| --- | --- | --- |
| 器件建模 | 工作区、跨导与模型的限制 | 教学模型的 I–V 扫描和参数说明 |
| 放大电路 | 工作点、增益、主极点、摆幅 | 手算与 AC / 瞬态仿真的对照 |
| 设计权衡 | 增益、带宽、功耗与稳定性的取舍 | 固定测试条件下的参数扫描、误差与失败分析 |

MIT 6.301 偏重 BJT，适合训练分析方法。目标是 CMOS 模拟设计时，还要通过本校课程或其他适合的资料，系统补充 MOS 电流镜、差分对、集成运放、噪声和版图效应。

## 项目与申请材料怎样积累

为一个主项目建立以下目录，先把证据补齐，再考虑扩展功能：

```text
project/
  README.md       # 问题、目标、个人贡献与复现入口
  design/         # 电路图或 RTL
  tests/          # 测试、激励与检查方法
  results/        # 波形、曲线、报告和参数
  notes/          # 推导、失败记录与改进理由
```

- [ ] 用一页说明问题、约束、自己负责的部分与最终结果。
- [ ] 别人能够根据环境版本和步骤复现实验。
- [ ] 能解释一个方案取舍，并给出对照证据。
- [ ] 读一篇与项目相关的论文，区分论文结果、复现结果和自己的改动。
- [ ] 准备三分钟项目说明，并能用英文解释图表、方法和局限。

这些是本站的准备建议，不是清华规定的申请材料清单，也不存在本站承诺的“几门课 / 几篇论文即可录取”。未公开的成绩单、个人资料和申请材料可保存在[本机加密空间](private.md)。

## 现在就开始

如果还没有明确分支，本周只选择一门基础课，并做一个能独立解释的小练习。已有模电数电基础的话，从 HDL 小模块或一个放大器分析开始，在[学习路线](roadmap.md)标记进度，把实验记录连到[知识芯片](graph.md)。

## 与信息通信方向交叉学习

如果更关心调制、编码、接收和无线系统，查看[信息与通信工程路线](communications-roadmap.md)。信号、概率与 DSP 可以共用；电路实现与通信系统模型各有自己的验收目标。
