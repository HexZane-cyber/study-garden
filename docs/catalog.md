# 课程目录

先挑一门适合当前基础的课程，再安排每周可投入的时间。这里收录经官方入口核对的课程与实践指南；难度、先修顺序和每周时间是本站建议，不能替代课程官方要求。

集成电路与微电子方向可先阅读[专门路线](ic-roadmap.md)，再选择基础、数字 IC / EDA 或模拟 IC / 器件分支。

信息与通信方向见[专门路线](communications-roadmap.md)，可复用已有信号、概率和电磁场基础，再进入通信与无线方向。

想补中文讲解或寻找另一门主课，可直接浏览[优质课程链接](course-links.md)：收录北邮、浙大、西电、华中科大，以及 Berkeley、Stanford 和 NPTEL 的原始课程入口，按用途标注先修、资源形式和选学投入。

继续选进阶资源时，查看[名校课程重点与先修](university-courses.md)：新增 MIT、Stanford、Berkeley、ETH、EPFL、CMU 与 UIUC 的 12 门课程，按方向列出重点、先修能力与开课自查。

找题目和交作业入口时，查看[习题、测验与提交](course-practice.md)：逐项区分公开材料、在线自测和需要课程权限的正式提交，并附邀请码的官方获取说明。

下方时长是**本站对选学范围的估算**，含练习与复盘。每项资源的难点、范围和折算周数见课程页；完整估算口径见本页「如何使用」。

## 如何使用

**难度参考**：入门适合从本领域起步；基础需要对应的数学或编程能力；进阶需要较扎实的先修、推导或实现能力。具体难点见各课程页，研究生课程可按章节选学。

**时长口径**：所有总时长都是本站对指南所选范围的估算，含阅读 / 听课、独立练习与复盘；不含补先修、全部官方作业和正式考试。实践资源与教材采用选学范围，不能当作完整课程时长。课程页列明范围、每周建议投入和折算周数。先记录两周实际用时，再调整节奏。

可按「总时长预算」筛出估算上限不超过预算的课程，或按预计总时长、难度排序。时长排序按估算下限、再按上限比较；这些数字用于排计划，不是官方承诺。

**按自己的节奏选课**：设置「我的每周学习时间」，课程卡片、对比表和路线中的周数会随之更新。单门周期假设这些时间全部用于该课；「我的课程计划」则把已加入计划和正在学习的课程依次排列，汇总总投入。已在计划中的先修排在前面，计划外的先修会单独提示。在学课程按完整估算计入，不自动推断剩余时间。

**对比后再决定**：每张卡片可勾选「加入对比」，最多同时对比三项。筛选目录不会清空本次对比；对比本身不修改学习状态，点击「加入计划」才会保存。展开「我的课程计划」可导出 Markdown 清单；课程进度仍可通过原有 JSON 备份保存。每周时间偏好保存在本浏览器，换设备可重新设置。

目录每次显示 12 门，点击底部按钮继续展开；搜索和筛选始终覆盖全部资源。个人计划和课程详情中的「安排一次学习」会把课程带到工作台，生成一条 25 分钟的阅读任务草稿。可以修改内容和日期，确认加入后才保存。

按方向、难度和学习状态筛选，查看先修提示，再进入课程页阅读资源与阶段验收。状态保存在本浏览器；可导出学习进度 JSON，在另一浏览器导入。只记录学习状态，不包含私密文件或口令。未启用脚本时仍可使用上面的链接列表。

课程以官方材料为依据，不代表本站已完成所有课程。新增资源可通过[共建课程](contribute.md)推荐；审核后才会进入正式内容。
