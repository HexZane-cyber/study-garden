## 中文课程配套 { #chinese }

下列原课均在中国大学 MOOC。课程介绍能确认的测验范围已标出；没有确认独立公开题目页的，提供同主题公开作业。**原课题目、截止时间、重做与评分规则，请登录后查看所选学期。** 学校专属课与慕课堂的加入方法见[邀请码说明](#access)。

- [原课入口](https://www.icourse163.org/course/BUPT-1003377004)：公开介绍未确认独立题目页，登录所选学期查看测验与作业。

### 西电 · 半导体物理 { #xdu-semiconductor }

- [原课入口](https://www.icourse163.org/course/XDU-1472391161)：公开介绍未确认独立题目页，登录所选学期查看。
- **同主题公开练习：**[MIT 6.012 Assignments](https://ocw.mit.edu/courses/6-012-microelectronic-devices-and-circuits-spring-2009/pages/assignments/)，补载流子、结与 MOS 器件分析。它偏器件与电路，不覆盖半导体物理的全部内容。

### 华中科大 · 集成电路设计基础 { #hust-ic }

- [原课入口](https://www.icourse163.org/course/HUST-1003410006)：公开介绍未确认独立题目页，登录原课查看练习安排。

### 北邮 · 信号与系统 { #bupt-signals }

- [原课入口](https://www.icourse163.org/course/BUPT-1003556005) · [往期课程介绍](https://www.icourse163.org/course/BUPT-1003556005?tid=1003806003)：往期大纲包含单元测验，当前题目与可提交状态以选课页面为准。
- **同主题公开练习：**[MIT 6.003 作业与解答](https://ocw.mit.edu/courses/6-003-signals-and-systems-fall-2011/pages/assignments/)，可练卷积、系统响应和变换。这里的答案用于自测，不会提交至北邮课程。

### 北邮 · 通信原理 { #bupt-communications }

- **同主题公开练习：**[MIT 6.450 Assignments](https://ocw.mit.edu/courses/6-450-principles-of-digital-communications-i-fall-2006/pages/assignments/)。这门研究生课难度较高，先选与已学调制、噪声和检测对应的题目。

### 浙大 · 数字信号处理 { #zju-dsp }

- [原课入口](https://www.icourse163.org/course/ZJU-1206695830)：公开介绍未确认独立题目页，原课测验需登录查看。
- **同主题公开练习：**[MIT 6.341 作业与解答](https://ocw.mit.edu/courses/6-341-discrete-time-signal-processing-fall-2005/pages/assignments/)，可练离散系统、频域与滤波分析。该课是研究生层级，适合作为进阶补充。

### 浙大 · 数字系统设计 { #zju-digital-systems }

- [原课入口](https://www.icourse163.org/course/detail.htm?cid=1207050802)：公开大纲列出测试 1–4，以及 HDL 流程、仿真流程等实验作业；实际题目与提交期限在所选学期核对。
- **同主题在线判题：**[HDLBits](https://hdlbits.01xz.net/wiki/Problem_sets)，先练组合逻辑、寄存器与状态机，再做原课系统实验。HDLBits 判题结果不计入原课成绩。

### 成电 · 专用集成电路设计 { #uestc-asic }

- [原课入口](https://www.icourse163.org/course/UESTC-234015)：课程介绍说明配有习题库和实验视频；未确认公开独立题目页，登录查看具体安排。
- **同主题实践：**[Nand2Tetris 项目目录](https://www.nand2tetris.org/course)适合数字系统搭建；[MIT 6.374 作业](https://ocw.mit.edu/courses/6-374-analysis-and-design-of-digital-integrated-circuits-fall-2003/pages/assignments/)补数字 IC 分析。两者均不能替代 ASIC 全流程训练。

### 微波技术与天线 { #microwave-antennas }

- [原课入口](https://www.icourse163.org/course/detail.htm?cid=1206399806)：公开大纲列有微波网络、微波元件和天线基本理论等测验，登录所选学期查看题目与提交状态。
- **同主题公开练习：**[MIT 6.013 Assignments](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/pages/assignments/)，用于电磁场与波、传输线等基础训练，不是原课试卷。

### 西电 · 信息论与编码 { #xdu-information }

- [原课入口](https://www.icourse163.org/course/XIDIAN-1002199004)：公开介绍未确认独立题目页，原课测验需登录查看。
- **同主题公开练习：**[MIT 6.441 Assignments](https://ocw.mit.edu/courses/6-441-information-theory-spring-2010/pages/assignments/)，用于熵、互信息和编码定理等分析。研究生层级，先补概率与通信基础。

- **补充练习：**[MIT 6.012 器件与电路作业](https://ocw.mit.edu/courses/6-012-microelectronic-devices-and-circuits-spring-2009/pages/assignments/)，先巩固小信号模型与基本放大器。

### NPTEL · CDMA、MIMO 与 OFDM { #nptel-wireless }

### Stanford EE261 · 傅里叶变换及应用 { #stanford-ee261 }

- **原课材料：**[Assignments / Exams 目录](https://see.stanford.edu/Course/EE261)，包含多套作业、练习考试和归档考试材料。
- **直接开始：**[第一套题 PDF](https://see.stanford.edu/materials/lsoftaee261/PS-1-2007.pdf)。做完后回目录找对应解答；注意题目上的日期属于历史学期。
- **提交方式：**公开归档供自测，未提供面向本站用户的校内提交入口，无需找班级邀请码。

### Nand2Tetris · 从逻辑门到计算机 { #nand2tetris }

- **原课项目：**[12 个项目目录](https://www.nand2tetris.org/course) · [项目 1 与测试文件说明](https://www.nand2tetris.org/project01) · [官方在线 / 桌面工具](https://www.nand2tetris.org/software)。
- **自测方式：**下载或使用项目提供的测试脚本、预期结果文件，在官方工具中运行；按每个项目的验收说明推进。
- **提交方式：**公开项目可独立完成与保存。正式班级或平台的交作业方式需另看其要求，公开项目页没有通用班级邀请码。

### Cornell ECE4750 · 计算机体系结构 { #cornell-ece4750 }

- **原课材料：**[公开 Handouts](https://www.csl.cornell.edu/courses/ece4750/handouts.shtml) · [2026 秋季教学大纲 PDF](https://www.csl.cornell.edu/courses/ece4750/handouts/ece4750-syllabus.pdf)。可查处理器、缓存等讲义和实验说明，具体公开范围以页面为准。
- **正式提交：**当前大纲规定代码经 GitHub、实验报告 PDF 经 Canvas；不是向本站仓库提交。Canvas 课程内容与成绩需原校课程权限。
- **自学路径：**阅读公开实验要求，保留实现、测试与报告；没有校内权限时不承诺原课评分。加入信息以课程首页和大纲为准，未找到通用公开邀请码。

### Berkeley EE142 · 射频集成电路 { #berkeley-ee142 }

- **原课入口：**[作业说明](https://rfic.eecs.berkeley.edu/courses/ee142/hw.html) · [公开实验目录](https://rfic.eecs.berkeley.edu/courses/ee142/labs.html)。实验页有 ADS、LC 滤波器、调谐放大器及振荡器等材料链接。

- **补充题目：**[MIT 6.776 作业](https://ocw.mit.edu/courses/6-776-high-speed-communication-circuits-spring-2005/pages/assignments/)，研究生层级；[bCourses 加入说明](https://rtl.berkeley.edu/services-programs/bcourses)。

### Stanford EE263 · 线性动态系统 { #stanford-ee263 }

- **学习记录：**把仿真参数、误码率曲线与解释写入自己的笔记，课程交互任务不等同于高校正式实验成绩。

## 把练习变成自己的成果 { #workflow }

1. 从上面的原课或同主题练习中选择一小组题，记下课程、学期和题号。
2. 在[工作台](dashboard.md)添加一个练习任务，给自己留出独立完成的时间。
3. 保存推导、仿真设置、测试输出和错题复盘；私密材料可放入[本机加密空间](private.md)。
4. 有公开解答或测试脚本时再核对，写清楚错误来自概念、计算还是实现。
