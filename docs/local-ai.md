# 本地 AI 助手

在网页中下载一个小模型，用来解释概念、给习题提示、检查解题条件与单位。也可以连接自己已经运行的本机 Ollama。本站不收取 API 密钥、不接入云端聊天接口。

## 第一次使用 { #setup }

### 方式一：网页内下载并运行

1. 用更新的桌面 Edge / Chrome 打开本页或[原创习题](exercises.md)，点击“检测 WebGPU”。需要安全上下文（HTTPS 或 localhost）与可用的显卡适配器。
2. **先试 Qwen2.5 0.5B**，点击“下载并加载模型”。验证成功后可卸载，再试 1.5B。
3. 等待下载、编译和初始化完成，再提问。关闭页面会卸载内存中的模型；已下载的缓存可供下次加载使用。
4. 不需要时点击“停止 / 卸载”；想释放浏览器存储，卸载后选择同一模型，再点击“删除所选模型缓存”。

| 模型 | 权重等文件的下载量估计 | WebLLM 配置参考显存 | 适合先做什么 |
| --- | --- | --- | --- |
| Qwen2.5 0.5B Instruct · 4 bit | 约 0.3 GB | 约 0.95 GB | 验证设备与连接，简单概念问答 |
| Qwen2.5 1.5B Instruct · 4 bit | 约 0.9 GB | 约 1.63 GB | 中文学习讨论、基础习题提示 |

下载量不含所有运行时开销；显存数字来自 WebLLM 配置，实际分配和速度随设备变化。**Core Ultra 7、32GB 内存可以从小模型开始尝试，但不能据此保证显卡兼容或推理速度。** 短问题更适合这两个小模型，复杂证明、精确计算和代码需要人工核验。

首次加载会请求 Hugging Face 的模型文件和 GitHub 上的 WebAssembly 运行库；提问文本由网页中的模型处理。模型包在浏览器 Cache API 中缓存，不是下载到“下载”文件夹的桌面软件；浏览器清理数据或存储压力可能移除缓存。文件已缓存也不代表整个网站从此完全离线可用，初始化仍可能检查远程资源。网络中断时可重试，不要把未完成状态当成完整下载。

下载只由按钮触发；平时浏览课程不会加载 AI 引擎或模型权重。运行库固定为 WebLLM 0.2.86，重计算放在工作线程中。网页只显示纯文本回复，不执行模型返回的 HTML 或脚本。

### 方式二：连接本机 Ollama

如果 WebGPU 不可用，可自行安装 [Ollama 官方客户端](https://ollama.com/download)，再在终端下载一个本地模型，例如：

```powershell
ollama pull qwen2.5:1.5b
```

这条命令由你在自己电脑执行，会下载模型文件。不要在网上随意复制未知安装脚本。Ollama 的模型包与网页 WebLLM 缓存相互独立，不能直接共用。

网页默认连接 `http://127.0.0.1:11434`。从正式站点访问本机服务时，需要允许**网页的来源**。如果遇到 CORS 限制，可按 [Ollama 官方 FAQ](https://docs.ollama.com/faq) 配置 `OLLAMA_ORIGINS`。一种仅对当前终端启动的服务生效的 PowerShell 示例为：

```powershell
$env:OLLAMA_ORIGINS = "https://hexzane-cyber.github.io"
ollama serve
```

来源是协议和主机，不包含 `/study-garden/` 路径。启动前需退出已运行的 Ollama 服务，避免 11434 端口被占用。若你通过桌面程序启动服务，应按官方说明设置对应进程的环境并重启程序；在另一个终端设置不会改变已运行的进程。本站不会替你修改环境变量或网络配置。

切换面板为“连接本机 Ollama”，点击“读取本机模型”，选择已安装模型，再发送问题。浏览器可能要求授予当前网站本地网络访问权限；只在确认访问的是自己启动的服务时允许。仍连接失败时，检查服务状态、来源配置及浏览器提示；不需要关闭浏览器安全机制，也不要把服务绑定到公网。

本站只允许回环地址，过滤明确标记为 `:cloud` 或带 `remote_host` 的模型。实际服务由你管理，请确认选用本地权重；网页无法证明自定义服务内部怎样处理请求。停止请求会取消浏览器等待，不保证本机服务立即结束全部计算。

## 与原创习题配合

在[原创习题](exercises.md)选择一题：

- **只给提示**：提示词不附带本站参考解答；模型仍可能自行推导出答案。
- **检查我的解答**：附带题目、你的作答和本站参考要点，检查条件、单位与推理。
- **逐步讲解**：可在面板内切换，按“把题目填入提问框”重新填入。

你可以修改提问后再发送。对话只保留在当前页面内存中，点“导出本次对话”才会生成本地明文文件。不会自动把 AI 回复写进笔记或改变练习分数；也不会自动读取加密私密空间。
