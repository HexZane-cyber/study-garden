# 原创习题

先独立作答，再逐条查看提示，最后对照解析。这 20 道题由之芯编写，覆盖电路与模拟 IC、数字 IC、信号处理、通信与信息论，**不是学校真题或官方作业**。建议用纸笔保留推导过程。

??? info "答题、筛选与分享说明"

    数值题只填数值，单位按题目指定，可用 `3.2e-3`，暂不解析表达式。选择题和数值题自动检查；解释题提供自查要点，不自动判分。题目中的理想模型与近似条件是解题的一部分。

    可以按**练习状态**筛选：未作答、已作答待检查、待纠错、检查通过，以及解释题待自查。修改作答后状态会更新，当前题目仍留在原位；点击“刷新题目列表”应用最新状态，“返回全部习题”只清空筛选，保留记录。解释题不自动认定掌握。

    每题的“复制单题链接”只分享题目编号，不包含个人作答。即使在本机预览中使用，分享链接也使用配置的正式网站地址；打开后聚焦这一道题。

## 让本地 AI 帮助思考

点击题目卡片的“本地 AI 提示 / 检查”，会把这道公开题目和你的作答填入下面的面板。**仍需你点击发送**；不会读取私密空间、其他笔记或整个浏览器的记录。可以一直留在本页讨论不同题目，无需重复加载模型。

<div id="local-ai-app"></div>

首次使用请看[模型下载与本机连接说明](local-ai.md#setup)。练习记录保存在当前浏览器，可以用题目列表下方按钮导出；它目前单独备份，不包含在旧版“数据与备份”中。导出的作答是明文，请自行保管。AI 对话在刷新或离开页面后清空。
