## 建议学习顺序

1. 可综合逻辑、状态机与时序
2. 同步、接口和模块集成
3. 从测试用例到项目演示与报告

## 练习与项目

本站练习建议：实现 UART、同步 FIFO 或 SPI 控制器之一，覆盖复位、边界条件和异常输入；先仿真，再选择是否上板。

每次实验保留假设、环境版本、输入参数、结果与误差解释，遇到失败也记录定位过程。

## 阶段验收

- [ ] 能解释阻塞与非阻塞赋值的使用场景
- [ ] 能用 testbench 捕获一次真实设计错误
- [ ] 能说明时钟、复位和接口约束

完成状态只用于记录自己的学习，不代表取得课程学分或达到招生要求。

## 口头解释练习

仿真通过为什么不等于硬件一定能运行？

先用三分钟给出直觉解释，再用图、公式或实验结果支持结论。这是本站自测题，不是清华面试原题。
