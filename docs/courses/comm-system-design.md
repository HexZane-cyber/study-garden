## 建议学习顺序

1. 先定义链路与模块的输入、输出及指标
2. 比较算法精度、定点位宽与吞吐需求
3. 对一个小模块建立测试和 RTL 实现

## 练习与项目

本站练习建议：实现一个短 FIR 或相关器，比较浮点、定点与 RTL 输出，记录误差、延迟和资源。

保留模型假设、参数与单位、工具版本、结果图和失败记录。先做小规模基线，再扩展复杂度。

## 阶段验收

- [ ] 能追踪一个系统指标到模块约束
- [ ] 能解释位宽和误差的权衡
- [ ] 能复现测试并说明个人实现范围
