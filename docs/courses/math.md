## 怎么开始

每节保留一道手算题和一个数值实验。不要只记公式，尝试解释维度、秩和投影为何有用。

建议把每周安排拆成“阅读 / 听课 → 独立练习 → 测试 → 记录疑问”，先连续执行两周，再根据实际投入调整计划。
