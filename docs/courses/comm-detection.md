## 练习与项目

本站练习建议：为高斯噪声中的已知信号建立检测器，扫描门限，画出虚警率与检测概率的关系，并检验样本数影响。

实验至少保留参数、单位、模型假设、工具版本、随机种子与失败记录。先完成理想基线，再逐项增加复杂度。

## 阶段验收

- [ ] 能定义假设、观测与判决规则
- [ ] 能区分虚警、漏检和估计误差
- [ ] 能解释一条 ROC 曲线及其适用条件
