## 怎么开始

优先补齐 C 和调试再推进实验。公共实验、课程提交系统和在校账号权限不是同一回事。

建议把每周安排拆成“阅读 / 听课 → 独立练习 → 测试 → 记录疑问”，先连续执行两周，再根据实际投入调整计划。

## 阶段验收

以下是本站建议的自测目标，完成标记只记录自己的进度，不是课程证书或官方评分。

- [ ] 解释整数表示和溢出
- [ ] 跟踪一次函数调用中的栈变化
- [ ] 用实验观察缓存局部性对性能的影响
- [ ] 完成一项系统练习并写明测试方法
