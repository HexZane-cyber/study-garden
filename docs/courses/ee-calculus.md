## 先修与学习范围

熟悉高中数学与基本代数，可先做章节诊断再决定学习速度。

本课是单变量微积分。器件、电磁场方向还需另补多元微积分、常微分方程与大学物理，不能用本课替代全部数学先修。

## 建议学习顺序

1. 导数、局部线性化与泰勒近似
2. 积分、累积量与简单微分方程
3. 把数学表达式接到 RC 电路模型上

## 练习与项目

本站练习建议：用 Python 比较 RC 充电解析解与简单数值积分，改变步长并记录误差。

每次实验保留假设、环境版本、输入参数、结果与误差解释，遇到失败也记录定位过程。

## 阶段验收

- [ ] 能用一阶展开解释“小信号”近似
- [ ] 能求解简单一阶微分方程
- [ ] 能说明数值步长如何影响误差

完成状态只用于记录自己的学习，不代表取得课程学分或达到招生要求。
