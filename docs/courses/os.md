## 怎么开始

固定一个学期的工具链、教材和实验版本，不混用不同年份的代码。每次修改前保留可运行的提交。

建议把每周安排拆成“阅读 / 听课 → 独立练习 → 测试 → 记录疑问”，先连续执行两周，再根据实际投入调整计划。

## 阶段验收

以下是本站建议的自测目标，完成标记只记录自己的进度，不是课程证书或官方评分。

- [ ] 运行 xv6 并定位一个用户程序入口
- [ ] 追踪系统调用从用户态到内核的过程
- [ ] 画出页表与虚拟地址转换关系
- [ ] 解释一个并发错误并设计复现方法
