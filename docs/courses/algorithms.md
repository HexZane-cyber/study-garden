## 怎么开始

先写朴素算法和测试，再优化复杂度。记录为何选择某种数据结构，而不只是保存最终代码。

建议把每周安排拆成“阅读 / 听课 → 独立练习 → 测试 → 记录疑问”，先连续执行两周，再根据实际投入调整计划。

## 阶段验收

以下是本站建议的自测目标，完成标记只记录自己的进度，不是课程证书或官方评分。

- [ ] 能区分并估算时间与空间复杂度
- [ ] 实现并测试一种排序或搜索结构
- [ ] 解释图遍历与最短路的不同约束
- [ ] 独立写出动态规划状态与转移并证明合理性
