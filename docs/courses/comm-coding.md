## 建议学习顺序

1. 硬判决、软判决与编码增益
2. 线性分组码、卷积码与译码
3. 图上编码等进阶主题的入口

## 练习与项目

本站练习建议：实现一个小型线性分组码，对比编码前后的结果；保持能量归一化和码率定义明确，同时报告额外开销。

实验至少保留参数、单位、模型假设、工具版本、随机种子与失败记录。先完成理想基线，再逐项增加复杂度。

## 阶段验收

- [ ] 能解释码率和冗余的作用
- [ ] 能说明硬判决和软判决保留的信息差异
- [ ] 能在公平比较条件下报告性能

## 口头解释练习

加入冗余以后，“误码率更低”为什么还不够说明方案更优？

先给出直觉，再用一个公式、图形或对照实验支持结论。这是本站自测练习，不是清华历年考题。
