## 建议学习顺序

1. 从单个随机变量过渡到随机过程
2. 离散状态模型及其长期行为
3. 从模型假设推导并检验统计量

## 练习与项目

本站练习建议：实现一个有限状态马尔可夫链，比较理论稳态分布和长时间采样频率，说明初始状态与样本长度的影响。

实验至少保留参数、单位、模型假设、工具版本、随机种子与失败记录。先完成理想基线，再逐项增加复杂度。

## 阶段验收

- [ ] 能区分随机变量和样本路径
- [ ] 能列出有限状态模型的转移关系
- [ ] 能说明稳态结论需要哪些条件

## 口头解释练习

一条很长的样本路径，是否总能代表总体统计规律？

先给出直觉，再用一个公式、图形或对照实验支持结论。这是本站自测练习，不是清华历年考题。
