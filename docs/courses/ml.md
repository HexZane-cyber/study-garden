## 怎么开始

先完成一个小数据集的可复现实验，再扩展模型。不要用测试集反复调参。

建议把每周安排拆成“阅读 / 听课 → 独立练习 → 测试 → 记录疑问”，先连续执行两周，再根据实际投入调整计划。

## 阶段验收

以下是本站建议的自测目标，完成标记只记录自己的进度，不是课程证书或官方评分。

- [ ] 建立训练集、验证集与测试集
- [ ] 解释回归损失与分类指标的差别
- [ ] 观察过拟合并尝试控制模型复杂度
- [ ] 保存实验配置、随机种子和评估结果
