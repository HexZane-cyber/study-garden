## 怎么开始

归档课表与项目说明必须配套。先确认 SQL 和 C++ 基础，不把系统课程的完成标记等同于已具备全部要求。

建议把每周安排拆成“阅读 / 听课 → 独立练习 → 测试 → 记录疑问”，先连续执行两周，再根据实际投入调整计划。
