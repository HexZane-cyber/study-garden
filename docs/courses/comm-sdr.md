## 建议学习顺序

1. 复数基带、频谱与滤波的直觉
2. 数字调制、噪声与脉冲成形
3. 从理想链路到频偏、定时与文件回放

## 练习与项目

本站练习建议：用 Python 先实现理想同步 BPSK 基带链路，再只加入一种非理想因素；记录参数、误码统计和频谱变化。

实验至少保留参数、单位、模型假设、工具版本、随机种子与失败记录。先完成理想基线，再逐项增加复杂度。

## 阶段验收

- [ ] 能说明 IQ 数据的含义和采样率
- [ ] 能复现实验并保留随机种子
- [ ] 能解释理想模型与接收结果之间的差距

## 口头解释练习

星座图旋转或扩散时，怎样区分频偏、定时和噪声问题？

先给出直觉，再用一个公式、图形或对照实验支持结论。这是本站自测练习，不是清华历年考题。
