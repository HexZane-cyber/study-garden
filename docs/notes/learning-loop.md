# 建立自己的学习循环

## 从问题开始

学习一段内容之前，先写下希望回答的问题。阅读结束后，用自己的语言重新回答，再通过一个最小例子检查。

## 理解与验证

例如在[数据结构与算法](../courses/algorithms.md)中，知道某个算法的复杂度只是开始，还需要解释输入规模如何影响执行次数。

在[Python 项目](../courses/python.md)中，把理解写成可运行的代码，再记录与预期不一致的地方。

## 留下可继续的笔记

每次结束前记录四件事：今天的问题、当前的解释、验证方式、下一步。这样下次回来时，不必重新找回上下文。

写作格式可以参考 [Markdown](../tools/markdown.md)，实验内容参考[实验记录](experiment.md)。
