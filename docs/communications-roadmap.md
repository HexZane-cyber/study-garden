## 分支一：无线通信与信息理论

建议在基础之后学习：[数字通信原理](courses/comm-principles.md) → [信息论](courses/comm-information.md)，再根据兴趣选择[信道编码](courses/comm-coding.md)与[无线通信](courses/comm-wireless.md)。[随机过程](courses/comm-random.md)可在概率基础牢固后并行补充。

重点留下三类证据：一个清楚定义的信道模型、一条经过理论或基准核对的性能曲线，以及一份说明假设和取舍的短报告。不要只比较曲线高低，还要说明码率、能量、带宽、复杂度和信道状态信息是否一致。

## 分支二：通信信号处理与实践

从[通信系统入门](courses/comm-intro.md)与[DSP](courses/ee-dsp.md)进入[PySDR 实践](courses/comm-sdr.md)，先完成理想同步链路。对接收、感知或估计感兴趣时，继续[随机过程](courses/comm-random.md)与[检测估计](courses/comm-detection.md)。

如果希望把接收算法落到硬件，可交叉选学[HDL 与数字系统实验](courses/ic-fpga.md)，尝试定点 FIR 或小型相关器。硬件实现时重新检查位宽、溢出、吞吐率与时序，不能直接把浮点仿真结果视为硬件效果。

## 网络与电磁方向的衔接

[6.02](courses/comm-intro.md)提供分组与网络层面的入门视角。希望研究协议实现时，可在系统编程基础到位后进入[CS144 计算机网络](courses/networks.md)，具体 C++ 与系统先修见该页；通信物理层知识不替代网络协议实现能力。

对天线、射频和高速链路感兴趣，可补[电磁场与应用](courses/ee-em.md)和[电路基础](courses/ee-circuits.md)。电磁场指南不是完整的天线、微波或射频电路课程，这些可以作为下一阶段专门扩展。

## 三个可复现的小项目

### 1. BPSK 基带链路与误码曲线

- [ ] 明确比特映射、信道、噪声和判决规则，先验证无噪声情况。
- [ ] 固定随机种子和统计长度，扫描信噪比并记录误码率。
- [ ] 在相干检测、理想同步、AWGN 等假设满足时，与相应理论结果对照。
- [ ] 核对实数 / 复数噪声方差、每比特能量与每符号能量的换算。
- [ ] 增加一种非理想因素，解释偏离基线的原因。

### 2. 已知信号检测与 ROC

- [ ] 定义有信号与无信号两种假设，写清观测模型。
- [ ] 扫描门限并统计虚警率、检测概率和样本数量。
- [ ] 改变信噪比，解释 ROC 的变化；避免把漏检和估计误差混为一谈。

### 3. 多径或衰落条件下的链路对照

- [ ] 从简单平坦衰落开始，记录信道模型与接收端已知信息。
- [ ] 在公平条件下比较基线与一种分集、均衡或编码方法。
- [ ] 保留参数、版本、图表生成脚本、失败记录与个人贡献说明。

以上为本站原创练习建议，不是课程官方评分任务或招生面试原题。先完成纯软件仿真或合法取得的数据回放即可，不要求购买设备。项目材料可以存进[个人私密空间](private.md)，希望公开的部分再按[上传流程](publish.md)发布。

## 与清华公开教学信息的参照

清华电子工程系[招生教学概况](https://www.ee.tsinghua.edu.cn/zsjx/gk.htm)说明其包含信息与通信工程学科。校方公开的[2022 年本科培养方案](https://www.tsinghua.edu.cn/jxjywj/bkzy2022/zxzy/23.pdf)中包含信号、概率与随机过程、通信及相关实验，也列有 DSP、编码和通信信号处理等方向课程。本站用这些公开范围组织基础和实践，不宣称与清华课程一一等同。
