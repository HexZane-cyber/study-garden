## 中文电路与器件 { #chinese-circuits }

<div class="grid cards" markdown>

-   ### 北邮 · 电路分析基础 { #bupt-circuits }

    **中文 · 基础 · 中国大学 MOOC**

    适合先建立电路模型与分析方法，再进入模电、数电。课程涵盖电阻网络、动态电路和正弦稳态等内容。

    - 建议先修：微积分、线性代数、复数与大学物理电学。
    - 选学投入：**60–100 小时**，核心分析方法与代表性习题。
    - 搭配本站：[电路与电子学指南](courses/ee-circuits.md)。

    [进入课程 →](https://www.icourse163.org/course/BUPT-1003377004)

-   ### 西电 · 半导体物理 { #xdu-semiconductor }

    **中文 · 进阶 · 中国大学 MOOC**

    适合补器件设计背后的物理图像。课程介绍半导体中的电子状态、杂质、载流子统计与非平衡载流子等内容。

    - 建议先修：大学物理与固体物理基础；原课程列出固体物理先修。
    - 选学投入：**60–100 小时**，选读核心物理概念与推导练习。
    - 搭配本站：[半导体器件指南](courses/ee-devices.md)。

    [进入课程 →](https://www.icourse163.org/course/XDU-1472391161)

-   ### 华中科大 · 集成电路设计基础 { #hust-ic }

    **中文 · 基础至进阶 · 中国大学 MOOC**

    用于从模电、数电过渡到 IC 专业学习。课程把器件、工艺、CMOS 电路和版图等基础内容连起来。

    - 建议先修：电路分析、模拟电子技术、数字逻辑。
    - 选学投入：**70–120 小时**，核心章节与小型设计分析；不含完整设计项目。
    - 搭配本站：[集成电路路线](ic-roadmap.md)。

    [进入课程 →](https://www.icourse163.org/course/HUST-1003410006)

</div>

## 中文信号与通信 { #chinese-communications }

<div class="grid cards" markdown>

-   ### 北邮 · 信号与系统 { #bupt-signals }

    **中文 · 基础 · 中国大学 MOOC**

    适合将时域、频域与系统响应放在一起理解，也可与英文资料对照。课程包含连续与离散信号分析及变换方法。

    - 建议先修：高等数学、线性代数、复变函数、电路分析。
    - 选学投入：**60–100 小时**，卷积、变换和系统响应的核心章节与练习。
    - 搭配本站：[信号与系统指南](courses/ee-signals.md)。

    [进入课程 →](https://www.icourse163.org/course/BUPT-1003556005) · [往期课程介绍](https://www.icourse163.org/course/BUPT-1003556005?tid=1003806003)

-   ### 北邮 · 通信原理 { #bupt-communications }

    **中文 · 基础至进阶 · 中国大学 MOOC**

    适合建立点到点链路的分析框架。内容涉及信号与随机过程、调制、数字传输及编码等主题。

    - 建议先修：信号与系统、概率论；随机信号基础需要同步补齐。
    - 选学投入：**70–120 小时**，主要传输模型、代表性计算与一个链路仿真。
    - 搭配本站：[通信系统入门](courses/comm-intro.md)与[通信方向路线](communications-roadmap.md)。

    [进入课程 →](https://www.icourse163.org/course/BUPT-1002543002)

-   ### 浙大 · 数字信号处理 { #zju-dsp }

    **中文 · 基础至进阶 · 中国大学 MOOC**

    适合从信号分析转向离散实现，重点包括离散系统、DFT / FFT 与数字滤波器。

    - 建议先修：信号与系统、复数和基础数值编程。
    - 选学投入：**60–100 小时**，变换、滤波核心章节及小型数值实验。
    - 搭配本站：[DSP 指南](courses/ee-dsp.md)。

    [进入课程 →](https://www.icourse163.org/course/ZJU-1206695830)

</div>

## 芯片设计进阶 { #ic-extensions }

<div class="grid cards" markdown>

    **英文 · 基础至进阶 · 公开讲义与课程资料**

    适合把半导体、MOS 小信号模型、放大器和运放设计放到同一条主线中学习。这里直接链接教师课程站的讲义目录。

    - 建议先修：电路分析与基础器件知识。

-   ### IIT Madras · Analog IC Design { #nptel-analog }

    - 建议先修：基础电路、信号与系统、MOS 模拟电路。
    - 选学投入：**70–120 小时**，选学关键设计章节与晶体管级分析练习。

    适合想系统理解数字芯片实现流程的人。课程串联 RTL、综合、验证、时序与物理实现，并包含工具演示。

    - 建议先修：数字逻辑、Verilog、基本时序概念和命令行。
    - 选学投入：**80–140 小时**，核心流程与一个小模块的工具练习。
    - 搭配本站：[RTL 到 GDS 实践](courses/ic-eda.md)；环境安装和排错另留时间。

## 按当前目标选择 { #choose }

如果更希望用中文打基础，可以选「北邮电路 → 北邮信号 → 北邮通信」，再按兴趣进入浙大 DSP 或半导体物理。固体物理基础尚未建立时，先补相关概念，再进入西电半导体课程。

如果模电数电已经学过，数字 IC 可从华中科大课程梳理概念，再结合 RTL 到 GDS；模拟 IC 可先对照 Berkeley EE105 的器件和放大器讲义，再进入 NPTEL Analog IC Design。无线方向在通信原理之后选择 MIMO / OFDM，变换基础卡住时回到 Stanford EE261 的相关单元。

每个方向先选一门主课。其他链接可以按疑问查阅，不必把相近课程全部重学。选课建议是本站对内容和先修的判断，具体范围仍以原课程大纲为准。

| 当前目标 | 可采用的选课顺序 | 先留下什么成果 |
| --- | --- | --- |
| 数字 IC 与 FPGA | 中文数字系统主课二选一 → 小型 RTL 模块 → Cornell 体系结构或 RTL 到 GDS | 一个有测试与波形的模块，再逐步扩大范围 |
| 通信理论与算法 | 信号与概率基础 → 通信原理 → 西电信息论；穿插 MathWorks 入门实验 | 一个明确假设和参数的误码率对照 |
| 射频与天线 | 电路与器件 → 模电、电磁场 → 微波与天线 → Berkeley EE142 | 一组匹配、噪声或电路响应的分析结果 |

这里的箭头表示本站建议的衔接。微波、射频、体系结构等分支不必一起推进；先确定一个方向，再回到所选课程的大纲核对要求。
