# 复习卡

<noscript>复习卡需要启用 JavaScript。你仍可以阅读[课程目录](catalog.md)和[学习路线](roadmap.md)。</noscript>

## 怎样使用

1. 阅读文章时，选中一段正文，点击「制作复习卡」；也可以在这里直接创建。
2. 用一个具体问题作为正面，答案尽量简短。例如：「二分查找为什么要求区间有序？」
3. 到期后先尝试回忆，再点击「揭示答案」，根据实际掌握情况安排下次复习。

可以先在「我的回忆」中写下自己的回答，揭示后与参考答案并排在同一卡片里对照。不会自动判分；你的临时回答不写入卡片或备份，换卡或离开页面后清空。输入时可用 **Ctrl / ⌘ + Enter** 揭示答案。

本次目标可选 5、10、20 张，进度只统计当前页面内完成的复习，刷新后重新开始。多张卡片到期时，可点击「换一张，稍后再想」；这不会推迟原卡的到期时间，也不会记作已复习。

「再想想」安排在 10 分钟后，「有点难」在 1 天后；「记住了」依次为 1、3、7、14、30、60 天，「很轻松」提前使用下一档间隔。间隔从本次点击时刻起算。这是固定间隔的小工具，不会预测你的记忆效果。

可使用空格揭示答案，再用数字 1–4 选择掌握程度；编辑表单时不会触发这些快捷键。

## 找卡片与保护草稿

“我的卡片”可搜索问题、答案和分组，并筛选全部、现在到期或以后复习，按添加顺序、到期时间或最近更新排序。列表显示匹配数量；这些筛选只改变列表，不会切换正在回忆的卡片、揭示答案或更改复习进度。列表仍沿用上方选择的复习分组，“清除列表搜索与筛选”不会改变该分组。

卡片有文章来源时，列表、编辑区和练习区都可以在新标签页打开来源文章，保留当前页面的填写内容。

切换去编辑另一张卡片，或点击“清空草稿 / 取消编辑”时，上一份未保存的编辑可以通过“恢复上一份编辑草稿”取回。只保留一份；若当前也有未保存内容，恢复时会交换这两份草稿。它们都只存在于当前页面内存中，不会自动写入浏览器存储、备份或 GitHub。关闭或刷新页面后无法恢复；请先保存卡片或复制内容。编辑区有未保存改动或仍有可恢复草稿时，会请求浏览器显示离开提示，提示是否显示取决于浏览器行为。确认不需要上一份草稿后，可点击“清除恢复草稿”，核对提示再清除；当前编辑框的内容不会改变。

编辑过程中若另一页修改了同一张卡片的内容，保存会停止并保留当前草稿，避免旧内容覆盖新版本。请先复制草稿，再取消编辑、重新打开最新卡片核对。另一页仅更新复习时间或掌握程度时，仍可保存文字编辑，并保留最新复习进度。

## 数据保存在这里

复习卡保存在当前浏览器，不会上传到 GitHub，也不会自动跨设备同步。它们使用浏览器普通存储，**没有加密**；敏感课本和笔记请继续放在[个人私密空间](private.md)。

导出备份是明文 JSON，包含问题、答案、分组、来源和复习进度。导入会合并卡片，同一编号保留更新时间较新的版本。清理浏览器数据会丢失尚未备份的卡片。
