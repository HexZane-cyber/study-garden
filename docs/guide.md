# 如何使用这本手册

## 按目录阅读

左侧目录按学科分类，每门课和每篇笔记都是一个独立的 Markdown 页面。右侧目录跳转到当前文章的小节。手机上可以点击左上角打开导航。

## 搜索内容

顶部搜索支持中文和英文，能够查找标题和正文。没有必要记住一篇笔记在哪个目录，输入概念即可。

## 建立知识连接

笔记中使用普通 Markdown 相对链接关联其他文章：

```markdown
这里用到了[向量与矩阵](../courses/math.md)中的知识。
```

构建时会根据文章链接生成[知识关系图](graph.md)。链接指向的文章成为相邻节点，不需要另外维护图谱文件。

## 编辑与上传

文章右上角的铅笔按钮可打开 GitHub 编辑器。新增笔记上传到 `docs/notes/`，提交到主分支后会自动加入导航、搜索和知识关系图。

详细流程见[上传与发布](publish.md)。

## 草稿工作区

如果希望先在网页中整理 Markdown，可以使用[本地草稿工作区](workbench/index.html)。那里支持导入、编辑和导出；草稿保存在当前浏览器，需要提交到 `docs/notes/` 才会成为手册正文。

!!! warning "区分草稿与正式笔记"
    草稿保存在浏览器；正式文章保存在 Git 仓库。定期备份草稿，发布时检查最终内容。

## 私密课本与笔记

不希望公开的课本和 Obsidian 笔记请放入[个人私密空间](private.md)。内容在当前浏览器加密保存，不写入仓库；换设备需要加密备份和原口令。

## 一起补充课程

通过[共建课程](contribute.md)填写课程推荐。投稿进入公开提案池，经过维护者审核后才会进入正式课程目录。私密空间中的文件不会自动进入投稿。

## 快捷操作与阅读设置

如果地址以 `127.0.0.1` 或 `localhost` 开头，标题下方会出现“本机预览 · 连接与启动帮助”，展开即可查看启动和停止方法，以及正式网站入口。服务没有启动时，浏览器无法加载这段提示，需要先在项目文件夹双击 `start-preview.cmd`。不同地址下的个人记录分别存储，切换入口不会自动迁移数据。

每页标题下方可打开“快速打开”，也可使用 **Ctrl / ⌘ + K**。输入页面标题或用空格组合关键词（例如“MIT 信号”），搜索本站目录、收藏和最近阅读；置顶收藏会优先列出，页面会显示匹配数量。方向键选择，Enter 打开，Esc 关闭。正文内容仍使用顶部全文搜索。

阅读工具支持调整字号、专注阅读、复制当前链接。文章会在本浏览器记住阅读位置，再次打开时点击“继续上次阅读”返回；不会突然自动跳动。图谱与私密资料页不记录此阅读位置。

“继续上次阅读”会显示上次位置的百分比；它表示页面滚动位置，不代表课程完成度。不同文章分别保存位置，保存前会读取最新记录，减少多标签页之间的覆盖。滚动后切换标签页或离开页面时会尝试立即补存；仅打开文章不会新建位置记录。若浏览器阻止存储或原记录无法解析，工具栏会提示保存问题，并保留原记录。

指向站内链接时，浏览器可提前加载少量目标页面；支持省流量设置的浏览器会在省流量或低速网络时停止预加载。首次访问与外部网站连接仍取决于实际网络。

## 选课与记录进度

先在[课程目录](catalog.md)按方向、难度和状态挑选课程，再用[学习路线](roadmap.md)查看站内先修与下一步建议。每门课可以标记“未开始 / 已加入计划 / 正在学习 / 已完成”；状态只保存在当前浏览器，不代表官方成绩。通过“导出学习进度”保存 JSON 备份，导入时补充缺失记录，同课程保留本机现有状态，不涉及私密文件。

课程目录还支持最多三项并排对比。设置自己的每周时间后，可查看各课程周期；展开「我的课程计划」，查看已加入计划与正在学习课程的顺序、总投入和缺少的站内先修，并导出 Markdown 清单。周数基于本站所选范围估算；在学课程仍按完整投入计算。

## 把计划放进工作台

[学习工作台](dashboard.md)集中显示课程进度、任务和专注时间。可以给任务关联课程、设置日期，完成后打勾；计时支持暂停和跨页面继续，结束后保存到当天统计。工作台的任务与计时可单独备份。标题下方“外观与背景”提供赤雾、轨迹和静夜三种风格，以及背景浓度和可选的指针光晕。

在课程详情或个人课程计划点击「安排一次学习」，会进入工作台并带入一条可编辑的阅读任务草稿。也可以在工作台为计划中的课程选择阅读、练习或回忆动作及建议时长；检查内容和日期后点击「加入任务」才会保存，不会自动修改课程进度或启动计时。

## 从阅读到复习

任务、复习卡、课程进度和阅读收藏可以在[数据与备份](backup.md)中按类型导出，在另一台设备预览后合并。该备份是明文 JSON，加密空间中的课本和笔记仍需单独导出 `.sgvault`。

在文章中选中一段文字，点击标题下的“制作复习卡”，会带着摘录进入[复习卡](review.md)草稿。补充一个具体的问题，保存后即可练习。先回忆，再揭示答案并选择掌握程度；工作台会提示到期卡片。复习卡使用普通本机存储，不是加密私密空间，可以单独导出 JSON 备份。
