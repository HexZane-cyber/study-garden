# Markdown 写作

## 基础格式

使用一个一级标题命名文章，再用二级和三级标题组织内容。目录会根据这些标题自动生成。

````markdown
# 笔记标题

## 我想解决的问题

这是正文，可以使用 **加粗** 和 `行内代码`。

```python
print("learn by doing")
```
````

## 关联其他笔记

使用相对路径链接，例如[Git 与知识管理](git.md)。普通链接既能用于阅读，也会成为知识关系图里的连线。

## 表格与提示

| 内容 | 建议 |
| --- | --- |
| 定义 | 用自己的话解释 |
| 例子 | 保留一个最小例子 |
| 实验 | 记录输入、输出和观察 |

!!! tip "先写清楚，再慢慢完善"
    不必一次写成教程。先记录当前问题和理解，再补充验证过程。
